# 介绍

**Orbien** 是一款基于 **Rust** 语言开发的高性能内网穿透工具，能够将位于内网的服务安全、高效地暴露到公网。通过建立稳定的反向隧道突破防火墙限制，适用于远程调试、内网服务公开、开发测试、物联网设备接入等多种场景。

## 为什么选择 Orbien？

Orbien 以 Rust 编写，天然具备内存安全、零成本抽象与高并发能力。相较于同类工具：

- **多协议隧道**：支持 TCP、UDP、HTTP、HTTPS、SOCKS5 协议
- **传输层** 支持TCP、QUIC、KCP、WebSocket多种传输协议可选
- **多路复用**：支持TCP多路复用，一条物理连接承载多条逻辑数据流，降低开销和延迟
- **HTTPS** HTTPS 按 SNI 透传，域名证书在本地，可选客户端TLS终止
- **安全** ：支持 TLS 与 mTLS加密传输，保证数据安全性
- **运维**：提供轻量服务端Web界面和跨平台原生桌面客户端，方便运维监控
- **跨平台**：支持 Linux、Windows、macOS、FreeBSD 多架构

- **内存占用更低**：常驻内存仅约 5–10 MB，远低于基于 Go 的同类工具
- **延迟更稳定**：多路复用 + QUIC/KCP 传输，弱网环境下表现更优
- **部署更简单**：单二进制文件，无需运行时依赖
- **安全性更强**：内置 TLS / mTLS，支持 Token 鉴权

## 核心功能

### 代理协议

| 协议 | 说明 |
|------|------|
| TCP | 通用 TCP 端口转发，适用于数据库、SSH 等 |
| UDP | 无连接 UDP 转发，适用于 DNS、游戏服务器等 |
| HTTP | HTTP 反向代理，支持自定义域名 |
| HTTPS | 按 SNI 透传，证书保留在本地，可选客户端 TLS 终止 |

### 传输层

| 传输协议 | 适用场景 |
|----------|----------|
| TCP | 默认传输，稳定可靠 |
| QUIC | 弱网 / 高丢包环境，低延迟首选 |
| KCP | 对实时性要求高的场景（游戏、音视频） |
| WebSocket | 需要穿越 HTTP 代理或防火墙时使用 |

### 其他特性

- **TCP 多路复用**：一条物理连接承载多条逻辑工作流，显著降低连接建立开销
- **TLS / mTLS**：支持双向证书认证，防止中间人攻击
- **Token 鉴权**：服务端可配置 Token，拒绝未授权客户端连接
- **Web 管理面板**：内置轻量 Web UI，实时查看隧道状态与流量统计
- **跨平台桌面客户端**：提供 GUI 客户端，支持 Windows / macOS / Linux
- **多平台多架构**：支持 Linux、Windows、macOS、FreeBSD，覆盖 x86_64 / ARM64 等主流架构

## 典型使用场景

- **开发调试**：将本地 `localhost:3000` 暴露到公网，方便 Webhook 回调或远程演示
- **数据库访问**：将内网数据库端口安全映射到云服务器，供远程工具连接
- **SSH 远程管理**：穿透 NAT 后 SSH 登录家庭/办公内网机器
- **IoT 设备接入**：嵌入式设备通过 QUIC/KCP 上报数据，适应不稳定网络
- **私有服务公开**：将自建 Gitea、Nextcloud 等服务安全地对外提供访问
